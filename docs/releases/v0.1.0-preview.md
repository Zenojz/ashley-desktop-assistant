# Ashley v0.1.0 preview

This is the first downloadable preview of the Ashley Community Edition for
Apple Silicon Macs running macOS 13 or newer.

## What is included

- Transparent 3D desktop avatar with assembly, fracture, rotation, and gestures
- Realtime voice conversation through OpenAI or Doubao using your own account
- Bundled “Hey Jarvis” wake word and experimental local Ashley voice enrollment
- Weather, Apple Maps, app launch and quit, macOS Spaces, and experimental music control

The archive does not include API credentials, personal wake-word models, voice
recordings, the private Codex bridge, or the separate holographic map.

## Before you try it

The app is ad-hoc signed and **not Apple notarized**. macOS may prevent a
downloaded copy from opening. If that happens, use the
[source build instructions](https://github.com/Zenojz/ashley-desktop-assistant#install-and-run).

Create `~/Library/Application Support/Ashley/.env` with your chosen voice
provider's credentials before launching the packaged app. The
[README](https://github.com/Zenojz/ashley-desktop-assistant#api-credentials)
lists the required settings. Never share this file or include its values in
an issue.

“Ashley” wake through personal acoustic matching is experimental and can
false-wake around television, music, or other speakers. The bundled word-level
wake phrase is “Hey Jarvis”. Music controls can be affected by changes to
Kugou or NetEase Cloud Music.

## Feedback

Please [report installation or runtime problems](https://github.com/Zenojz/ashley-desktop-assistant/issues/new/choose)
with your macOS version, Mac chip, installation method, and steps to reproduce.
Remove API keys, recordings, and personal information from logs first.
