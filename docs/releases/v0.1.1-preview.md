# Ashley v0.1.1 preview

This Apple Silicon preview updates the desktop app to Electron 44.5.1 and
sharp 0.35.5. It also migrates music search's clipboard handling to Electron's
new asynchronous API, preserving the clipboard contents after a search.

The dependency lockfile now uses patched versions of the vulnerable transitive
dependencies that have fixes available. One advisory remains in
`http-cache-semantics`, a dependency of the development-only packaging tool;
upstream has not published a patched version. It is not bundled with the app.

## Before you try it

Ashley requires macOS 13 or newer on Apple Silicon. The archive is ad-hoc
signed and **not Apple notarized**. macOS may prevent a downloaded copy from
opening. If that happens, use the
[source build instructions](https://github.com/Zenojz/ashley-desktop-assistant#install-and-run).

Create `~/Library/Application Support/Ashley/.env` with your chosen voice
provider's credentials before launching the packaged app. The
[README](https://github.com/Zenojz/ashley-desktop-assistant#api-credentials)
lists the required settings. Never include this file in an issue.

The archive does not include API credentials, personal wake-word models,
voice recordings, the private Codex bridge, or the separate holographic map.
The bundled wake phrase remains “Hey Jarvis”; local Ashley voice enrollment is
experimental.

## Feedback

If you try the preview, please [submit a test report](https://github.com/Zenojz/ashley-desktop-assistant/issues/new?template=preview_test_report.yml)
whether installation succeeds or fails. Include your macOS version, Mac chip,
installation method, and what you actually tested. The form lets you mark
untried features as **Not tested**. A source-build report is useful, but it
does not verify installation of the Release ZIP. For a reproducible defect,
you can also [open a bug report](https://github.com/Zenojz/ashley-desktop-assistant/issues/new?template=bug_report.yml).
Remove API keys, `.env` files, recordings, and personal information from logs
before posting. No installation or interactive test on another Mac has been
confirmed yet; user reports will provide that evidence.
